- 摄像头通过以太网直连电脑，红外设备在线。

- 当前没有探测到 `192.168.1.202`，所以可见光机芯未确认在线；可能设备不是双光型号，也可能可见光模块未接入/未上电/已改 IP。

## 4. 运行环境要求

手册推荐环境：

- 操作系统：Windows 7 / Windows 8 / Windows 10，32 位或 64 位，推荐 64 位 Windows 10。
- CPU：主频 2GHz 以上双核处理器。
- 内存：2GB；Windows 7/8/10 建议 4GB 以上。
- 显卡：显存大于 512MB。
- 硬盘：50GB 以上空间。
- Windows 7 首次运行前需要安装 `.NET Framework 4.8` 补丁包。
- Windows 8/10 一般自带所需补丁，无需额外安装。

## 5. IRTool Pro 能做什么

IRTool Pro 是 Yoseen 为红外热像仪及其衍生产品开发的红外分析软件，核心能力包括：

- 实时显示全辐射红外热像图。
- 获取和显示画面温度分布。
- 通过 TCP/IP 获取热像图温度值。
- 通过 RTSP 获取热像仪视频流。
- 支持温度流、视频流、双光监测、数据查看四类工作模式。
- 支持全局测温和局部测温对象。
- 支持高温/低温追踪。
- 支持实时温度曲线。
- 支持报警阈值配置和报警抓拍。
- 支持手动保存、录像、温度流录制、曲线数据录制。
- 支持离线回放和分析历史数据。
- 支持设备参数配置、网络参数配置、图像参数配置和设备维护。
- 支持断电/重启后的自动重连、自动载入模板、保存上次连接属性。

## 6. 软件工作模式

| 模式 | 用途 |
| --- | --- |
| 温度流模式 | 获取红外温度流，做测温、曲线、报警、温度数据保存 |
| 视频流模式 | 获取红外视频流，做画面预览和基础测温 |
| 双光监测模式 | 同时预览和配置红外与可见光画面 |
| 数据查看 | 查看手动保存数据，离线预览、回放和分析 |

单红外设备通常使用“温度流”和“视频流”。  
双光设备使用“双光”模式，并配置红外 IP 与可见光 IP。

## 7. 测温能力

温度流模式支持：

- 1 路设备温度流接入。
- 全局测温。
- 最多 15 个局部测温对象。
- 测温对象类型包括：
  - 点测温
  - 线段/折线测温
  - 多边形/区域测温
  - 屏蔽区
- 每个测温对象可以显示或计算：
  - 最高温
  - 最低温
  - 平均温
  - 高温追踪点
  - 低温追踪点
  - 温度曲线

测温对象可以移动、删除、重命名，并可配置单独的发射率和报警参数。

## 8. 报警能力

软件支持 5 类报警逻辑：

| 报警类型 | 含义 |
| --- | --- |
| 超温报警 | 最高温大于温度 1 |
| 低温报警 | 最低温小于温度 1 |
| 温度区间报警 | 最低温大于温度 1 且最高温小于温度 2 |
| 温度区间外报警 | 最低温小于温度 1 或最高温大于温度 2 |
| 高温区间报警 | 最高温大于温度 1 且小于温度 2 |

报警时可以自动抓拍，报警图片保存在 `DataAlarm` 目录。

## 9. 图像与显示配置

软件可以调整红外显示效果：

- 调色板。
- 图像算法：
  - `PHE`：适应性强，只保证温度与灰度单调关系。
  - `LINEAR`：适应性较差，但保证温度与灰度线性关系。
  - `CK`：仓库监控场景。
  - `HW`：户外监控场景。
- 增益：范围 `0.1` 到 `10`，增益越大细节越多，噪点也越大。
- DDE 等级：范围 `0` 到 `8`，`0` 为关闭，用于增强细节。
- 亮度、对比度。
- 温宽调节。
- 温度标记：按高温、低温、区间内、区间外对指定温度范围着色。
- 裁剪区域。
- 数字变焦：`1x / 2x / 4x`。

## 10. 测温修正与环境参数

软件/设备配置中包含：

- 全局发射率，默认 `0.97`。
- 测温对象发射率。
- 大气修正。
- 环境温度。
- 相对湿度。
- 能见度。
- 降雨强度。
- 降雪强度。
- 目标距离。
- 红外窗口透过率。
- 红外窗口温度差。
- 温度漂移/温度偏移。

用途：当测温精度受环境、材料发射率、窗口材料或距离影响时，用这些参数修正测温结果。

## 12. 设备配置能力

IRTool Pro 的设备配置项包括：

- 基本信息：
  - 设备序列号
  - 设备类型
  - 设备名称
  - 硬件版本
  - 软件版本
  - 标定版本
  - 分辨率
  - 分辨率 + 帧率
- 数据设置：
  - 数据变换
  - 180 度翻转
  - X/Y 镜像
  - 数据率
  - 发送率
- 网络参数：
  - 是否使用静态 IP
  - 静态 IP
  - 子网掩码
  - 网关
  - MAC 地址
  - DNS
- 挡板校准：
  - 手动挡片校准
  - 自动挡板校准时间间隔
  - 温度间隔
  - 默认每 6000 帧或每 500mK 触发一次校准
  - 无挡板校正模式
- 图像输出：
  - 模拟视频
  - HDMI 制式
  - H.264 码率
  - 关键帧间隔
- 外部接口：
  - GPIO 外部联动
  - 串口配置或云台控制
- 维护：
  - 固件升级
  - 坏点补偿
  - 用户校准/上传校准文件

## 13. 双光和云台能力

双光设备支持：

- 红外画面预览。
- 可见光画面预览。
- 红外与可见光画面匹配。
- 可见光 IP、用户名、密码、RTSP 格式、RTSP 后缀、RTSP 传输方式配置。
- RTSP 传输方式支持 TCP 和 UDP，默认 TCP。

云台/镜头控制能力包括：

- 水平角 Pan。
- 垂直角 Tilt。
- 变焦 Zoom。
- 自动对焦。
- 远/近焦点调节。
- 光圈打开/关闭。
- 补光。
- 雨刷。
- 预置位设置。
- 预置位调用。

这些能力依赖具体硬件是否支持。

## 14. BatchTool 能做什么

`BatchTool.exe` 是批量 IP 搜索和设备管理工具，主要用于：

- 搜索在线红外热像仪。
- 查看设备 IP。
- 勾选设备后修改网络参数。
- 设置静态 IP。
- 修改子网掩码和网关。
- 当电脑和设备不在同一网段时，辅助把设备改到目标网段。

当前设备已经在默认网段，通常不需要改 IP。

## 15. 当前推荐使用方式

1. 确认电脑以太网为 `192.168.1.1` 或其他 `192.168.1.X` 地址，且不要占用 `.201` 和 `.202`。
2. 打开 `E:\IRToolPro_v2.4.0.0626\IRToolPro.exe`。
3. 在软件中选择或搜索设备 IP：`192.168.1.201`。
4. 单红外设备优先使用“温度流”模式，点击播放。
5. 如果只需要普通视频预览，可尝试“视频流”模式或 RTSP。
6. 浏览器管理页面可打开：`http://192.168.1.201/`。
7. 如果是双光设备但看不到可见光，检查 `192.168.1.202` 是否在线，或用 BatchTool/网页确认可见光 IP 是否被改过。

## 16. 当前已发现的问题/注意事项

- E 盘软件包不是传统 Windows USB 驱动包，没有发现 `.inf/.sys/.cat` 驱动文件。
- 这是网络型红外热像仪配套软件，通过以太网、TCP/IP、RTSP 和 SDK 通信。
- IRToolPro 日志中出现过预览接收超时/连接重置记录，说明设备能连接，但取流/预览配置可能还需要在软件界面中确认。
- `192.168.1.202` 当前无响应，所以可见光通道未确认可用。
- 如果 IRToolPro 搜索不到设备，检查是否有其他程序占用发现端口；软件语言文件提示发现功能依赖端口 `55511`。
